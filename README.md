# 🏏 Bowling Simulation

A realistic cricket bowling simulator built using **Unity (3D)** and **C#**, aiming to replicate the physics and mechanics behind real-world **fast** and **spin bowling**. It explores key dynamics like **swing**, **seam**, **spin**, and **pitch interaction**, making it useful for both gameplay prototyping and cricket analytics.

🔗 **GitHub:** [NitinYadav354/Bowling-Simulation](https://github.com/NitinYadav354/Bowling-Simulation)

---

## 🎯 Objectives

- Simulate realistic bowling mechanics: speed, pitch behavior, swing, and spin.
- Model real-world physical factors: air resistance, seam angle, pitch friction, and ball condition.
- Provide an interactive visual experience with dynamic camera views and trajectory tracking.

---

## ⚙️ Physics-Based Features

### Bowling Types
- Implements fast bowling and spin variations like **leg spin** and **off spin**.

### Swing Mechanics
- Conventional swing based on **seam position**, **ball velocity**, and **release angle**.

### Pitch Interaction
- Ball behavior changes based on **bounce point**, **surface friction**, and whether the ball is **new or worn**.

### Spin Dynamics
- Uses **Magnus effect** and **angular momentum** to simulate realistic drift and turn.

---

## 🎮 Visual Elements

- **Multiple Camera Views:** Includes bowler view, follow cam, side view, and pitch cam.
- **Trajectory Tracking:** Early-stage Hawkeye-style system for showing ball path from release to bounce and impact.
- **UI Elements:** Displays key data like ball speed, swing value, and bounce distance in real time.

---

## 🧰 Tech Stack

- **Unity Engine (3D)**
- **C#** for physics and logic scripting
- Custom physics modeling layered on Unity’s built-in engine
